# 验收记录

验收日期：2026-10-23。运行环境：Windows、Node.js v24.22.0、SQLite 3.53.3、Wrangler 4.152.0。

## 自动验证

- `node --test tests/*.test.mjs`：20 项测试通过。
- 注册与账号：账号唯一且不区分大小写、短密码被拒绝、默认 ID 与他人重复时拒绝注册、登录/登出、停用后会话立即失效。
- 账号自助维护：修改显示 ID 后看板展示新名字、他人 ID 冲突被拒绝、改密需要当前密码且会登出其他设备、旧密码立即失效。
- 登录限速：同一账号连续 8 次失败后返回 429，其他账号不受影响。
- 真实并发数据库测试：12 个独立线程/连接同时写入同一预约时段，1 个成功、11 个被数据库冲突触发器拒绝。
- 旧库升级：访问码时代的数据库可迁移到账号模型，有历史预约的旧身份保留为停用占位、无预约的被移除、索引与防重叠触发器重建。
- 导出测试：CSV 含 UTF-8 BOM、北京时间、状态推断、逗号/引号 ID 转义，且不包含密码哈希；JSON 与空库导出均正常。
- `wrangler deploy --dry-run`：Worker 打包及静态资源检查通过，识别 DB 与 ASSETS 绑定。
- `wrangler d1 migrations apply bookabeibei --local` / `--remote`：0001、0002 完整迁移通过。
- `tests/http-smoke.mjs`：分别针对 Node 本地入口和 Wrangler 的真实 Workers/D1 本地模拟运行，覆盖静态资源、CSP 安全响应头、注册登录、改 ID、8 个并发预约请求、看板、取消、立即使用、提前结束与登出。
- Node HTTP 的大请求体检查：返回 413 JSON 错误。
- 前端 JavaScript 与后端入口语法检查通过。

本地 HTTP 集成测试只允许 localhost 目标，每次运行会注册一个随机的一次性账号，不依赖预置成员：

```powershell
$env:SMOKE_URL = "http://127.0.0.1:8787"
node tests/http-smoke.mjs
```

请使用独立测试数据库；脚本会真实创建预约，并在结束时释放。

## 浏览器验收

在独立 `.data` 临时数据库上，用真实浏览器完整走了一遍：

- 未登录时点右上角「登录 / 注册」，弹窗默认在「登录」标签；切到「注册」后标题与按钮文案同步变化。
- 用中文账号 `群主` + 8 位以上密码注册，成功后自动登录，顶栏显示该账号，提示“注册成功”。
- 打开账号窗口把显示 ID 改成 `小杯同学`，顶栏、状态卡、预约卡片三处同步更新，提示“ID 已更新”。
- 点「现在使用杯杯」创建 30 分钟预约，看板上出现带“我”标记的卡片，状态卡显示使用者 ID 与结束时间。
- 退出登录后回到未登录态；用错误密码登录显示“账号或密码不正确。”，用正确密码登录后预约状态完整恢复。
- 浏览器控制台只有一条预期内的 401（错误密码那次请求）。

## 线上部署

已在 Cloudflare 免费计划（Workers 静态资源 + Workers API + D1）完成一次真实部署：

- 两版迁移（`0001_init.sql`、`0002_accounts.sql`）均可在远程 D1 正常应用。
- 用 Wrangler 的 workerd + 真实 D1 绑定运行 `tests/http-smoke.mjs`，全部通过。
- 中国大陆网络常见 `*.workers.dev` 不可直连（DNS 污染 + TLS 重置），上线前应用手机实测；必要时改用自定义域名。
- 本仓库不含任何账户、域名或数据库标识。
